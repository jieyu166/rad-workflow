# 《撼動華爾街的海龜交易員》成人高密度漫畫設計

## 目標

將已拆分的 14 個正文章節依原書順序改編為成人高資訊密度漫畫腳本與逐頁圖像生成提示詞。漫畫保留人物傳記、歷史事件、交易哲學、制度衝突與技術規則，同時避免先前作品反覆使用固定六格、問答講解與任務卡所造成的制式感。

本階段不生成圖片，只建立可供後續 `imagegen` 逐頁批次生成的完整製作包。

## 來源與適應邊界

- 來源：`outputs/novel-to-manga/turtle-trader-adult-dense/source-chapters/`
- 正文章節：第 1–14 章。
- 必須保留原書順序，不合併章節。
- 每章開頭必須提供完整章節摘要，不得省略；可使用條列式呈現。
- 真實人物、事件、績效、交易原則與公式不得憑空增加。
- 歷史原話只有來源文字明確支持時使用引號；其餘對白採忠於原意的漫畫化意譯。
- 本次不處理前言與章後附錄。

## 敘事架構

採歷史紀錄劇形式，直接以理查．丹尼斯、威廉．艾克哈特與海龜學員推動故事，不新增固定虛構講師或現代讀者角色。

旁白只負責：

- 年代與地點定位。
- 人物關係與必要背景。
- 無法自然放進人物行動的交易概念。
- 事件之間的時間跳接。

每章必須具備：

1. 視覺開場。
2. 核心問題或衝突。
3. 人物、制度或概念轉折。
4. 章末鉤子或餘韻。

## 版式策略

採「A：敘事變奏模組」為骨架，依章節內容局部借用：

- B：電影紀錄片，用於人物崛起、衝突、失敗、終止與收束。
- C：財經雜誌資訊漫畫，用於系統、公式、績效、心理特質與決策比較。

### 九種頁型

1. **電影式開場**：大型環境格搭配 1–2 個嵌格。
2. **斜切辯論**：對立人物、理念或決策的交鋒。
3. **檔案拼貼**：報紙、招聘廣告、合約、法律文件、照片與年份。
4. **行情螢幕**：價格曲線、突破、部位、盈虧與交易員反應。
5. **時間軸長卷**：人物成長、計畫進程與事件因果。
6. **人物群像**：招募、面試、學員差異、績效與特質。
7. **資訊拆解**：公式、規則、數字案例與圖解結論。
8. **決策矩陣**：選擇、風險、代價與後果。
9. **無框靜默頁**：計畫終止、失敗、孤獨與章末餘韻。

### 輪替規則

- 相鄰兩頁不得使用相同主頁型。
- 每章至少使用 4 種頁型。
- 10 頁以上的章節至少使用 6 種頁型。
- 每章最多 2 頁使用標準六格。
- 同一頁可以混合局部頁型，但只能有一個主視覺焦點。
- 純資訊頁前後必須安排人物行動或情境頁。
- 每頁必須有敘事功能與末格轉折、問題、衝擊或餘韻。

## 人物與歷史視覺規格

- 所有登場者均採原書真實人物，不合併、不新增虛構導覽者。
- 反覆出現的人物建立固定角色 ID 與角色基準。
- 跨年代時保留臉部骨架、眼型、體態與標誌性神態，只調整合理的年齡、髮型與服裝。
- 場景依年代區分：1960–70 年代交易廳、1983 年海龜培訓、正式交易期、計畫終止後的基金與媒體時期。
- 服裝、交易背心、紙本報價、電話、終端機與芝加哥商品交易場所景符合時代。
- 禁止出現智慧手機、平板或現代交易介面。

## 色彩與畫面語言

採有限色彩電影漫畫：

- 主色：深藍綠、紙張米色、銅金。
- 紅色：虧損、危機、訴訟或違反規則。
- 綠色：獲利、突破或正向決策。
- 人物傳記頁：偏寫實電影感。
- 交易概念頁：清楚、成熟、不幼稚的資訊視覺。
- 失敗與訴訟段落：降低彩度。
- 無框靜默頁：以留白或深色大面積打斷資訊洪流。

## 文字規格

- 所有可見文字使用繁體中文。
- 對白壓縮為漫畫可讀長度，不把原文段落直接塞入對話框。
- 長背景資料改為旁白、報紙摘要、文件標題或資訊圖標籤。
- 公式與交易規則保留必要符號、定義與數字案例。
- 同一格避免同時出現長對白、長旁白與複雜圖表。

## 每章交付內容

每章輸出一份完整 Markdown 漫畫腳本，依序包含：

1. 章節摘要：不可省略，可用條列式完整呈現。
2. 不可省略事件與概念。
3. 場景拆解。
4. 節拍表。
5. 頁面清單。
6. 每頁功能、版式 ID、格數、視覺焦點與章內銜接。
7. 逐格鏡位、構圖、人物、動作、表情、對白、旁白、音效與背景。
8. 每頁獨立圖像生成提示詞。
9. 該章來源覆蓋檢查。

## 圖像提示詞規格

每頁提示詞必須明確包含：

- `complete manga page`。
- 頁碼與頁面主題。
- 主頁型 ID 與格數。
- 角色 ID 與視覺基準。
- 場景、年代、道具與色彩規格。
- 每格的鏡位、動作與精確繁體中文文字。
- 前頁連續性與末格重點。
- 禁止合併格子、海報化、單張插畫化、加入無關人物、現代物件、亂碼與制式化固定六格。

## 生產順序

1. 建立全書角色、場景、風格與版式基準。
2. 依第 1 章至第 14 章順序生成腳本。
3. 每完成一章，更新來源覆蓋表與生產追蹤表。
4. 腳本確認後建立逐頁提示詞。
5. 執行全書章序、覆蓋率、頁型輪替與提示詞 QA。
6. 圖片生成留待使用者後續明確要求 `imagegen` 時執行。

## 品質驗證

- 14 個章節全部存在且順序正確。
- 每章均有不可省略的章節摘要。
- 原書各小節在 `source-coverage.md` 有對應頁面。
- 重要人物、事件、交易規則與公式均未遺漏。
- 相鄰頁版式 ID 不重複。
- 頁型數量符合章節長度規則。
- 標準六格未超過每章 2 頁。
- 純資訊頁前後具有情境或人物行動。
- 對白可放入漫畫氣泡，且人物歸屬清楚。
- 每頁提示詞均通過角色、格數、語言、頁碼、版式與負面限制檢查。
